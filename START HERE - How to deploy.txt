HOW TO DEPLOY (same as before)
------------------------------
1. Unzip this file. Open the folder "word-shuffle".

2. GitHub:
   - Open your existing WORD SHUFFLE repository on github.com
     (or make a new one: + > New repository, do NOT tick "Add a README").
   - Click "Add file" > "Upload files".
   - Select EVERYTHING inside the word-shuffle folder (Ctrl+A) and drag it
     onto the page. Drag the folders themselves (client, data, tools).
   - Click the green "Commit changes" button.

3. Render.com:
   - Existing service: it redeploys by itself after you commit. Wait for "Live".
   - New service: New + > Web Service > pick your repository, then set
        Build Command:  npm install
        Start Command:  npm start
     Environment (optional but recommended):
        TIKTOK_USERNAME     = your TikTok name (no @)   (or type it in Settings > Live)
        TIKTOK_SIGN_API_KEY = your Euler key            (or type it in Settings > Live)
        ADMIN_PIN           = a PIN so nobody else can change settings
        DATA_DIR            = /var/data  (only if you added a Render persistent disk,
                                          so saved settings survive redeploys)

4. Open your Render link on your phone.
   Safe workflow: stay in TEST mode, try the new settings, then switch to LIVE.


TRY THE NEW FEATURES IN 2 MINUTES (Test mode)
---------------------------------------------
 - ⚙️ -> ⏭ Next Round: turn OFF "Start the next round automatically", Save & Apply,
   press ✅ (solve as fake viewer). After the winner window the big ▶ button appears.
 - ⚙️ -> ✍️ Text & Effects: switch on "Confetti", press 👁 Preview.
 - ⚙️ -> ⏭ Next Round: "Rounds per session" = 3, Save & Apply, and play 3 rounds
   with the 🤖 bot to see the final leaderboard.
